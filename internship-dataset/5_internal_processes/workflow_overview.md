# Quy Trình Làm Việc Nội Bộ

Chúng tôi muốn các bạn thực tập sinh hiểu rõ cách làm việc tại công ty, từ khi nhận task đến hoàn thiện sản phẩm, nhằm đảm bảo hiệu quả và minh bạch.

---

## 1. Quy trình chung

1. **Nhận task từ mentor**  
   - Mentor giao nhiệm vụ qua hệ thống quản lý (Jira, Trello).  
   - Task có mô tả chi tiết, deadline và yêu cầu chất lượng.  

2. **Phân tích yêu cầu**  
   - Đọc kỹ yêu cầu, đặt câu hỏi nếu có phần chưa rõ.  
   - Lập kế hoạch, xác định các bước thực hiện.  

3. **Triển khai & cập nhật tiến độ**  
   - Thực hiện task theo kế hoạch.  
   - Cập nhật trạng thái task hàng ngày trên hệ thống quản lý để mentor theo dõi.  

4. **Gửi báo cáo cuối ngày**  
   - Tóm tắt công việc đã làm, khó khăn gặp phải và kế hoạch ngày hôm sau.  

5. **Review & feedback từ mentor**  
   - Mentor đánh giá chất lượng và tiến độ, đưa ra feedback.  

6. **Điều chỉnh & hoàn thiện**  
   - Thực hiện các điều chỉnh theo feedback để đảm bảo task hoàn thành tốt nhất.

---

## 2. Công cụ sử dụng & hướng dẫn tìm hiểu

### a. **Jira / Trello**
- **Chức năng**: Quản lý task, sắp xếp ưu tiên, theo dõi tiến độ, phân công công việc.  
- **Từ khóa tìm hiểu**: Agile, Scrum, Kanban, Board, Backlog, Sprint, Epic, Story Points.  
- **Gợi ý**: Xem tutorial về cách tạo board, tạo task, move task giữa các trạng thái.

### b. **Git / GitHub**
- **Chức năng**: Quản lý code, version control, cộng tác nhóm.  
- **Từ khóa tìm hiểu**: Git Flow, Branching, Commit, Push, Pull Request (PR), Merge, Rebase, Fork, Clone, Conflict Resolution.  
- **Gợi ý**: Tìm hiểu workflow chuẩn của công ty (ví dụ: feature branch → PR → review → merge main).

### c. **Notion**
- **Chức năng**: Lưu trữ tài liệu, quy trình, ghi chú dự án, quản lý knowledge base.  
- **Từ khóa tìm hiểu**: Page, Database, Template, Linked Database, Kanban Board.  
- **Gợi ý**: Xem cách tạo task list, template dự án, note và ghi chú công việc.

### d. **Slack / Teams**
- **Chức năng**: Trao đổi nội bộ, thông báo nhanh, chat nhóm, gọi video.  
- **Từ khóa tìm hiểu**: Channel, Thread, Direct Message (DM), Integration, Notification, @Mentions.  
- **Gợi ý**: Làm quen cách nhắn tin nhóm, mention mentor, tạo thread theo task.

### e. **Docker (và các công cụ DevOps liên quan)**
- **Chức năng**: Container hóa ứng dụng, tạo môi trường đồng nhất, dễ triển khai.  
- **Từ khóa tìm hiểu**: Container, Image, Dockerfile, Docker Compose, Volume, Port Mapping.  
- **Gợi ý**: Học cách build image, chạy container, dùng compose để setup multi-container.

### f. **Các công cụ khác**
- **VSCode / IntelliJ / PyCharm**: IDE để code, debug, linting.  
- **Postman / Insomnia**: Test API.  
- **Figma / Adobe XD**: Thiết kế UI/UX (nếu làm frontend).  
- **SQL / MySQL Workbench / DBeaver**: Quản lý cơ sở dữ liệu, query dữ liệu.  

> **Mẹo cho thực tập sinh**:  
> - Dành thời gian học trước các công cụ chính: Git, Jira, Docker.  
> - Tìm tutorial hoặc video trên YouTube, đọc documentation chính thức.  
> - Thực hành mini-project hoặc sample project để quen workflow thực tế.

---

## 3. Lưu ý khi sử dụng công cụ

- Cập nhật tiến độ thường xuyên trên Jira/Trello để mentor theo dõi.  
- Push code đều đặn, tạo PR đúng workflow, review lẫn nhau.  
- Lưu trữ tài liệu trên Notion, giữ ghi chú đầy đủ, dễ tra cứu.  
- Trao đổi rõ ràng trên Slack/Teams, mention đúng người liên quan.  
- Tuân thủ quy tắc bảo mật, không chia sẻ thông tin nội bộ ra ngoài.
