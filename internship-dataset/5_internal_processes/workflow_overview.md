
# Quy Trình Làm Việc Nội Bộ

## Quy trình chung
1. Nhận task từ mentor qua hệ thống quản lý (Jira/Trello).
2. Phân tích yêu cầu.
3. Triển khai & cập nhật tiến độ.
4. Gửi báo cáo cuối ngày.
5. Review & feedback từ mentor.
6. Điều chỉnh & hoàn thiện.

## Công cụ sử dụng
- Jira / Trello
- Git / GitHub
- Notion
- Slack / Teams
